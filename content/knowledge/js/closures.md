# 闭包（Closure）

## 基础要点

**闭包**是指函数与其**词法作用域**的组合——即使外部函数已经返回，内部函数依然能访问外部函数作用域中的变量。

```js
function createCounter() {
  let count = 0;
  return function () {
    count += 1;
    return count;
  };
}

const counter = createCounter();
counter(); // 1
counter(); // 2
```

`counter` 持有对 `count` 的引用，这就是闭包：`count` 不会被垃圾回收，因为它仍被内部函数引用。

## 深入原理

### 词法作用域
JavaScript 采用**词法作用域**（静态作用域）：函数能访问的变量由**定义位置**决定，而非调用位置。闭包正是建立在这个机制之上。

### 变量捕获的本质
闭包捕获的是**变量本身（引用）**，而非值的快照。因此循环 + `var` 是经典陷阱：

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0); // 输出 3 3 3
}
```

`var` 没有块级作用域，三个定时器共享同一个 `i`，循环结束时 `i === 3`。

**修复方式：**

```js
// 方式一：let 提供块级作用域，每次迭代独立绑定
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0); // 0 1 2
}

// 方式二：IIFE 制造闭包，固化当时的 i
for (var i = 0; i < 3; i++) {
  ((j) => setTimeout(() => console.log(j), 0))(i);
}
```

## 常见应用场景

- **数据私有化**：用闭包模拟私有变量（ES2022 之前没有真正私有时）。
- **函数工厂 / 柯里化**：根据参数生成定制函数。
- **防抖 / 节流**：闭包保存定时器句柄与计时状态。
- **模块模式**：IIFE 返回公开接口，隐藏内部状态。

## 面试要点

- 闭包 = 函数 + 词法环境，捕获的是变量引用而非值。
- 循环陷阱根因是 `var` 无块级作用域；`let` 或 IIFE 可解。
- 闭包会延长变量生命周期，过度使用可能增加内存占用。
